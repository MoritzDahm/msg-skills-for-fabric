# Power BI Governance Change Log

Structured, append-only record of governed changes. Do not delete entries;
mark superseded/reverted items with `Status: Reverted` and reference the
follow-up CR in `Notes`. Read this file top-to-bottom for full history, or
scan for a `Workspace:`, `Semantic model:`, `Report:`, or `Items changed:`
line matching what you're looking for. See the `powerbi-governance` skill's
`references/ledger-schema.md` for the full field spec.
